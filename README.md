# 🍹 CocktailGenius

**Proyecto Final - Fundamentos de Inteligencia Artificial**

## Descripción
CocktailGenius es una plataforma de mixología impulsada por IA que democratiza la coctelería de autor.

## Herramientas utilizadas
- **IA Generativa:** ChatGPT (textos), Canva AI (imágenes), ElevenLabs (voz), CapCut (video)
- **Chatbot:** Botpress
- **Machine Learning:** Google Colab + Python (Regresión Lineal, R²=66.9%)
- **Automatización:** n8n → Google Sheets
- **Web App:** Streamlit

## Requisitos cumplidos
✅ Identidad del proyecto (nombre, logo, slogan, misión, visión)
✅ Portafolio con 5 funcionalidades
✅ Contenido multimedia con IA (video 27s)
✅ Chatbot funcional (Botpress)
✅ Automatización (n8n + Google Sheets)
✅ IA Generativa en 3+ áreas (textos, imágenes, video, voz)
✅ Modelo ML simple (Regresión Lineal con dataset, gráfica, resultados)
